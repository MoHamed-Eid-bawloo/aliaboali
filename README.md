# نظام إدارة متجر الهاتف

تطبيق React عربي RTL لإدارة متجر الهواتف والإكسسوارات، يعمل بالكامل داخل المتصفح. البيانات محفوظة في IndexedDB ولا يحتاج إلى خادم أو قاعدة بيانات خارجية.

## التشغيل

```bash
npm install
npm run dev
```

## بناء نسخة الإنتاج

```bash
npm run build
npm run preview
```

ارفع محتويات مجلد `dist` إلى أي استضافة مواقع ثابتة.

## الوظائف

- إدارة المنتجات والمخزون مع تحذير المخزون المنخفض.
- فواتير البيع والشراء مع التحقق من الكميات وتحديث المخزون تلقائياً.
- العملاء والموردون والمصروفات والخزينة.
- لوحة تحكم وتقارير مالية قابلة للطباعة.
- تصدير واستعادة نسخة احتياطية JSON مع تحقق وتأكيد قبل الاستبدال.
- سجل تدقيق وحركات مخزون محفوظة في IndexedDB.

## البيانات

يحفظ التطبيق البيانات في قاعدة `mobile-shop-db` داخل IndexedDB الخاصة بالمتصفح. لا تستخدم البيانات `localStorage` كقاعدة بيانات.
